# Security Log Investigation

## Project Overview

This project analyzes a synthetic authentication log to identify suspicious login behavior and reconstruct a likely incident timeline.

## Objectives

The investigation focuses on:

- Normalizing timestamps, IP addresses, accounts, actions, and results
- Detecting brute-force attempts
- Detecting password spraying
- Identifying unusual access
- Creating an incident timeline
- Separating evidence from assumptions

## Project Files

- [Investigation Notebook](investigation-notebook.md)
- [Detection Rules](detection-rules.md)

## Dataset

The investigation uses a synthetic authentication log supplied for the EdVyro Cyber Security task.

## Investigation Summary

The log is analyzed to identify suspicious authentication patterns and recommend appropriate response actions.

Further analysis, detection findings, and the incident timeline are documented in the project files.
